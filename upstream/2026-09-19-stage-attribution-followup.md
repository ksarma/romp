The sweep's old eight-directory walk omitted every other directory and the root files (373 tracked files at 639043a31, tools/ and vendor/ among them, 355 of them text by the scan's rule) and, inside its eight roots, every file off its suffix allowlist or under a pruned directory (68 more, 45 of them text), none of which named a routed block, so it was complete by luck; the scan now lists the tree with git ls-files (cached plus untracked, ignores honoured), skips symlinks and reads a file as text when its first PROBE bytes (RoutingStatements.PROBE) hold no NUL byte and the whole of it decodes as UTF-8, at 639043a31 in a clean worktree 3054 of the 3109 paths git lists read as text, 71.8 MB of them.

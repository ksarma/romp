Three items from the closing check of fork PR 797 (the stage-attribution fix), all tests and docstrings, and one folded from PR 834: _assert_stack_sample's docstring says what the check verifies (a frame's basename exists in one of the listed directories) and no more. The sweep's old eight-directory walk omitted every other directory and the root files (tools/ and vendor/ among them) and, inside its eight roots, every file off its suffix allowlist or under a pruned directory, none of which named a routed block, so it was complete by luck; the scan now lists the tree with git ls-files (cached plus untracked, ignores honoured), skips symlinks and reads a file as text when its first PROBE bytes (RoutingStatements.PROBE) hold no NUL byte and the whole of it decodes as UTF-8, in chunks through an incremental decoder, so a file that names no block costs one chunk whatever its size. No count of the tree or of the walk's gap is quoted: the counts move with every commit, and the class docstring gives the census as the command a reader runs at their own head (the ls-files listing split on NUL, symlinks, NUL-headed and undecodable files dropped, the rest counted and their bytes summed) and the walk's gap as that listing bucketed against the walk's roots, suffix allowlist and pruned names. The plant test writes a file in plans/ naming a routed block with a retired wording, asserts both pins red, removes it in a finally and asserts both green; a plant a killed run leaves behind is removed in setUpClass under the exclusive lock, and the healer removes only an untracked regular file. The scan holds a shared flock and the plant an exclusive one on a lock file in the worktree's git dir, resolved under a scrubbed git environment and opened read-only, so every process over that checkout waits on it, xdist workers and separate runs with their own TMPDIR alike. The docstring sentence that said a bare _push is foreign when no cycle is open was false under a literal reading, since ownership is a registration cycle() leaves standing; it now says a thread that opened no cycle and so was never registered as an owner, and the old phrase is refused by the sweep from here. The count of places stating the rule appears nowhere in the tree; the pin's docstring now defines it as the size of the swept file set, one entry per text file matching the block regex at least once, with the grep command that approximates it and how it differs, says the block regex is a one-directional proxy (prose that states the routing without naming a block, this entry included, is outside the sweep), and holds no count of statements.

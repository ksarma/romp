An inline svg's `fill`, `stroke`, `mask`, `clip-path`, `filter` or `marker-*` attribute holding a `url()` to another origin made the browser request that document the moment a chat message or a hovered file preview rendered, with no click: the sanitizer keeps all eight attributes and nothing after it on those two surfaces read them. What left was the reader's IP address, the time, the user agent, the page's origin for `mask` (a CSS image, sent as the Referer under the kernel's same-origin policy) and whatever path and query the author wrote into the `url()`. The surfaces reached are the kernel-served dashboard and the iOS web app, not the VS Code panes, whose `img-src` names only the webview's own resources and `data:` (read from the policy's text, not executed). Red before the fix, at 6cf6839ba and with the passes removed (2026-09-23, Chromium 151): the chat witness's logger received 19 requests and the hover witness's 10. `filter`, measured by the design study as fetching only same-origin in Chromium 151 (where figure-gate.ts's 2026-09-09 note said all eight fetched), reached neither logger; on the hover path the page's request event fired for it and no request arrived. It is removed by rule. The fix is one strip (paint-refs.ts dropRemoteRefs) run inside sanitizeMd by default and in the preview card's strip; the file viewer opts out and keeps its click gate. A residual, disclosed and tested: the notice card (feed.ts noticeBodyNodes) calls the preview's strip with an empty base, so its paint arm now removes a relative or root-relative same-origin paint reference that sanitizeMd's own pass kept (fail closed, no request); the same empty base already cost a notice body its relative, same-origin and data: images. Passing the page's URL there fixes both and is the notice card's own follow-up; file-preview.test.ts states the current behaviour and goes red when that call changes.

An .svg opened in its own tab (a Cmd, Ctrl or middle click on a path link to it in a viewed file, which opens the kernel's /file URL or the /remote/<host>/file relay's) was a document under a bare `sandbox`, which stops scripts and not loads. At 6e6ddf7d5 each tab fetched sixteen loads from the host its markup named (an image href and xlink:href, a CSS @import, a foreignObject img, a fill, a mask and a CSS fill paint reference, and nine more shapes a probe found: an feImage, a CSS cursor, a background image, an @font-face source, a stylesheet link, an image preload, a prefetch, an iframe and a video), the paint references and the font with no cookie and the rest with the browser's SameSite=None cookies for that host, none with a Referer. The kernel now sends `sandbox; default-src 'none'; img-src data: blob:; style-src 'unsafe-inline'; font-src data:` as one value on every svg success (HEAD, 206, 200), the relay's included: the tab loads nothing from another host, and an exported figure's data: raster and inline styles still render (tests/test_svg_tab_policy_browser.py). It reduces what leaves the machine, and it reaches the user as a notice at landing.

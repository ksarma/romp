Stage two of the usage-data plan (2026-09-18), stacked on the export (fork PR 764): one verb sends one file written by romp perf export --public to a receiver and nothing else. The receiver address is configuration and is EMPTY upstream: --receiver URL, else ROMP_PERF_RECEIVER, else ~/.config/romp/perf-receiver (the default-dir pattern); with none set the verb refuses and names the three settings, so an installation nobody configured sends nowhere, and no code carries an address. The receiver is unauthenticated, so the verb reads no token and sends none. The file is checked again as it stands (at most 1 MiB, strict JSON with no repeated key and the romp-perf-export/1 schema line, the export's own scan, walk and denylist check through check_document, a finding reported by kind and key path only); the verb prints the path, the byte size and the URL it will dial (a path in the address included) and asks for a yes on a terminal, refusing off a terminal unless --yes is passed (the agent's form; no setting or variable stands in for it, so nothing uploads from a cron). One POST to <receiver>/v1/upload (stdlib urllib, redirects refused with the Location never parsed, no proxy variable read, no cookies, six headers: Content-Type, Content-Length and User-Agent romp-perf-upload/1 from the verb, Host, Accept-Encoding: identity and Connection: close from the client, 30 s timeout); the only answer accepted is 201 with exactly {receipt: uuid4, retention_days: int, av: ok|skipped}; every other status, body or error is refused with a fixed line carrying only the status code or the error class. docs/reference.md states the request and response contract so any operator can write a receiver, the 180-day retention, the screening (vocabulary, antivirus) and deletion by receipt id; docs/guide.md names the upload as the one user-initiated exception to the local-only promise. The tests include an executed enumeration of the request a recording receiver saw (line, six headers, body bytes equal to the file). The stage-three trigger (an unattended sender) is the owner's later word and is not built.

title: Temp-directory hygiene, the child-process half, plus git hermeticity. `tests/__init__.py`'s mkdtemp hook (fork PR #201) records and removes what the test process itself mints, but not what its children make — kernels, git, a shell's `mktemp -d` — nor mkstemp files or `os.mkdir` paths (~5,600 such entries per full run before). `tests/conftest.py` redirects the process temp dir (`tempfile.tempdir` + `TMPDIR`, inherited by every child) into one private `romp-tests-*` root at import time and removes it whole in `pytest_unconfigure`, after the hook's `pytest_sessionfinish` sweep of the inside (controller and every xdist worker each own one); the package's state dir, minted before the redirect, goes with it; a root that survives removal is named on stderr. The same conftest floors git to no global/system config with a synthetic identity (`GIT_CONFIG_GLOBAL`, `GIT_CONFIG_NOSYSTEM`, `GIT_AUTHOR_*`/`GIT_COMMITTER_*`); the bats suites that build fixture repos `load git-hermetic` — four exist upstream (bootstrap-sh, docs-serve, install-sh, release-sh), three are fork-only (fork-remotes, gitleaks-config, pre-push-hook). The socket tests' inbox dir (`tests/test_kernel_socket_deliver.py`, upstream too) had pinned `dir="/tmp"` past any redirect and never removed it; it now follows the root, falls back to the system temp dir conftest recorded once per run (`ROMP_TESTS_SYSTEM_TMPDIR`, inherited by xdist workers) only when the socket path would not fit `sun_path`, and is removed at close. `test_kernel_worktree_display.TreeOf`'s class-level seed repo gets a tearDownClass. `tests/romp.bats` (upstream too) exports a no-op `romp-postal-service` stand-in as `ROMP_POSTAL_BIN` in `setup`, and `bin/romp`'s resume picker-check (one line) goes through that seam like `mail` and `refresh` — the script's own directory leads PATH, so nothing else can stand in: the real service, detached, minted a serve-token under the test's `$HOME` after teardown had removed it, re-creating four to six test dirs per run of that file. Pinned by `tests/test_tempdir_hygiene.py` (beside #201's hook checks: the in-run floors and child inheritance, no literal `dir=` in any tempfile call, the survivor notice, global and system `core.hooksPath` probes, and a nested pytest that must leave a fresh system temp dir untouched, serial and under xdist) and `tests/git-hermetic.bats` (the same two hooksPath probes; both proofs skip on git < 2.32 with one message).

Upstream carries the same two bindings (the judge's STATE is the romp root, the bus's is the root plus postal) and the same read in _presumed_closed, so rule 5 of its dead-session ladder is dead there too: every sid reaching it answers cannot-determine, and a dead sender's card settles only by rules 1 to 3. Re-checked at upstream/main for this round: its _write_remote_sids still writes the whitespace list, pruned by HEARTBEAT_TTL at every write and folded from every PEER_STATE row, from memory alone, and its judge still reads STATE/remote-sids. Found as a side finding of the fork's postal-bus tests PR (fork PR #894), where the reviewer's ruling asked for both STATE bindings to be read and the read to be run; the probe there confirmed it by execution and filed it for its own fix-tier PR.

Moving the reader to the writer's path alone would arm a rule that settles falsely, which the round-1 review of the fork's PR showed by two roads: a bus restarted from empty memory rewrote the mirror at its first poll naming nobody, so until its first exchange every sid live on another host was absent from the file and its local mirror store settled; and, under the legacy singleton scheme, the bus pruned an expired heartbeat's sid at every write, so a tunnel drop or a stalled peer longer than the 90 s TTL settled a live session on no new information. The mirror therefore changed shape: a JSON document with one row per presence source, the roster it last reported, whether the bus heard it in its current process, and whether its presence expired. The writer carries every host the previous file named and this process has not heard forward, unreachable, until its heartbeat or exchange arrives; an expired beat's row stays, marked. The reader presumes a sid closed only when a reachable host exists and none names it; a sid only an unreachable host names, a mirror with no reachable host, or a mirror of another shape (the old whitespace list, said once in the judge's log) answers cannot-determine, as the dead rule did. The kernel's link state gates reachability too (round 2's ruling by the reviewer): a host is reachable only when heard and the kernel does not hold its link down, so the down notify makes it unreachable at once with its roster kept (a host that is down cannot vouch for absence, and a session started there since its last roster is in no roster) and its next heartbeat or exchange heard with the link up makes it reachable again; the writer computes the `reachable` flag per row and the reader reads it, and the two cannot-determine reasons that turn on a source's state name the sources and what makes each unreachable. The gate reaches a peer's row under the alias the kernel dials, where this bus's own dial files it; a far bus heard only through its dials to us, before that fold, sits under the name it declares and has no link state (no event ties the two names before the fold): a disclosed residual with an executed witness in the mirror test module. Event-keyed, no grace period. One test runs the real writer and the real reader over one root under both root shapes through the first write, a restart, an expiry and the legacy shape. Fix tier: product code with tests red before it.

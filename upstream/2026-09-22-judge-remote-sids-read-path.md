Moving the reader to the writer's path alone would arm a rule that settles falsely, which the round-1 review of the fork's PR showed by two roads: a bus restarted from empty memory rewrote the mirror at its first poll naming nobody, so until its first exchange every sid live on another host was absent from the file and its local mirror store settled; and, under the legacy singleton scheme, the bus pruned an expired heartbeat's sid at every write, so a tunnel drop or a stalled peer longer than the 90 s TTL settled a live session on no new information. The mirror therefore changed shape: a JSON document with one row per presence source, the roster it last reported, whether the bus heard it in its current process, and whether its presence expired. The writer carries every host the previous file named and this process has not heard forward, unreachable, until its heartbeat or exchange arrives; an expired beat's row stays, marked. The reader presumes a sid closed only when a host vouches for absence and none names it; a sid only an unreachable host names, a mirror in which no host vouches for absence, or a mirror of another shape (the old whitespace list, said once in the judge's log) answers cannot-determine, as the dead rule did. The kernel's link state gates reachability too (round 2's ruling by the reviewer): a host is reachable only when heard and the kernel does not hold its link down, so the down notify makes it unreachable at once with its roster kept (a host that is down cannot vouch for absence, and a session started there since its last roster is in no roster) and its next heartbeat or exchange heard with the link up makes it reachable again; the writer computes the flags per row and the reader reads them, and the two cannot-determine reasons that turn on a source's state name the sources and why each cannot vouch. The events: the up notify plus the host heard since make a host vouch for absence, the down notify ends it at once, and for a far bus under its declared name the fold files its row where the alias's link reaches it.

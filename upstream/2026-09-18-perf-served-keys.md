Keys are the leak vectors of the served snapshot: builds.chat.bySession named its sid in every row, parses.bySid keyed the cold-parse table by sid prefix, the http table keyed GET /glossary/<term> per term and every requester-typed path (a scanner's probe, a home path, an attached host's op) until its cap, and connectPush.byApp keyed a client's declared app name verbatim. The rows are served by rank in max order; parses.perSession is {sessions, max}; /glossary/* is a collapsed family; every http key outside the checked-in route register _PERF_HTTP_ROUTES (one tuple per do_* method, held equal to the dispatch source by a test) folds to other; an app name is a key only when it fits an identifier grammar and while under a cap. One invariant test walks a whole snapshot built from planted synthetic state (a fake home path, the placeholder sid, TESTHOST, a glossary term, an exception message, a scanner path, a client app string) and asserts no absolute path, no uuid or 32-hex token, no planted text and no key outside an identifier grammar except in the http table and the byte tables keyed by joined identifiers (function names, stage marks and reason codes); it found 40 leaks across seven sites on the tree before the fixes, the byApp one no review had named among them. CI then found one more under pytest-timeout: the stack sample keyed each thread by its name, and pytest-timeout names its watchdog with the running test's path; the kind is now a word from a checked-in register of the kernel's own thread kinds (_THREAD_KINDS and _THREAD_KIND_PREFIXES beside _PERF_ROUTE_SEGMENTS, held equal to every construction site by the census test), other for any name outside it, and the invariant's key grammar accepts a register word or other alone. Shape changes: rank replaces sid in bySession rows; perSession replaces bySid; HEAD /version and other non-routes count under other. First half: perf-served-paths-and-text.

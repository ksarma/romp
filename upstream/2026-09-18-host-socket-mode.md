asyncio.start_unix_server binds and listens at the umask mode, and the chmod to 0600 landed one line later, so hosts/<sid8>.sock stood at the umask mode for the gap: the last member of the create-then-tighten class PR 789 closed for the kernel credential files, found in its round 1 (fresh-5) and split out as its own fix. Behind the owner-only state root, the one guard then, so a window, not a live hole; the umask is not a guard, since the live session host runs at 002, which leaves the group write bit an AF_UNIX connect needs (an earlier draft of this entry named it as one). The fix checks the published path's length against the socket path budget first (sun_path less its NUL, 107 on Linux: a published path over it is one the kernel can never connect to, and the bind's own check moved onto the temp's name once the temp had a name of its own, so at exactly 108 bytes a first cut published an unreachable socket and logged socket-ready), binds a writer-unique temp name beside the published one (the pid and random digits, the published name's length: the published path is the budget on a deep test root, and a fixed temp name was a shared name two hosts for one sid could cross), tightens it by path (fchmod is a no-op on a bound AF_UNIX socket on Linux), and renames it onto the published path, which is therefore born 0600. During its life at the umask mode the temp has one guard, the mode of hosts/, which both creators (the kernel's write_spawn_spec and the host's bind) make and keep 0700 by code, refusing a symlink or a foreign owner and reading a tighten back. Every failure on the road is loud and leaves nothing: a socket-bind-failed row with the step, the error class, errno and the path length (never the text, which carries the path), the CLI ended, the lease removed, exit 1. The kernel connects to the same documented path and no process-wide umask moves. Upstream main carries both halves: its host binds the published path the same way (kernel/session_host.py, start_unix_server then chmod), and both of its roads create hosts/ at the umask's mode (the spawn spec's mkdir with parents=True and the host's own).

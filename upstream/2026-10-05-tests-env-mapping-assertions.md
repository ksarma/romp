A failing unittest assertion prints its operands. assertNotIn(name, env) prints the whole container, assertEqual(env, want) prints both mappings, and mock's assert_called* methods print every call the mock recorded, arguments included. When the operand is an environment mapping, the failure report carries every value in it, and on a developer's machine those values include live API keys. Every such assertion now tests the one variable and prints a bool or a count: assertFalse(name in env, name), assertTrue(name in env, name), assertTrue(env == want, msg) or assertEqual(run.call_count, N, msg). tests/test_env_mapping_assert_census.py holds the rule. It reads every tests/*.py by AST and fails on an assertion, message or bare assert that renders an environment mapping of a shape it reads: os.environ, an attribute or string key named env or environ, a name bound to a copy or view of one (keys() included), the result of a callee that returns one, or such a mapping formatted, sliced or joined into a message. It fails when it finds nothing to watch, keeps an exact-site exemption list (empty), and its docstring lists the shapes it cannot see, with green plants pinning the ones a reader would most expect it to see. Tests only.

The project's tree at upstream/main (f4a572008, 2026-09-24) carries the same assertions. This census, run over it, finds 84 sites in 13 files. Seven more sites have three shapes the census cannot see: tests/test_credentials.py:514 tests a loop variable bound from the (cmd, env) pairs a stubbed spawn recorded; tests/test_judge_auth_billing.py:384, 404 and 449 call assert_not_called or assert_called_once on a mock of subprocess.run, which the judge calls with env=; tests/test_login_records.py:299, 300 and 302 test a child's dump of its environment, read back. That makes 91 in all. Each prints a whole environment mapping when it fails: os.environ itself at 7 sites, a child's environment or a session's stored environment at the rest. Upstream's tests/conftest.py masks, in pytest reports only, process-environment values of 16 characters or more (except names it exempts as paths or public) and credential-shaped tokens. It masks values inside the report text and leaves the mapping printed, with its names and every shorter value in the clear, and a plain unittest run has no hook at all.

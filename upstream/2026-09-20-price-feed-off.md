The kernel fetched a third party's price table (the public LiteLLM list on raw.githubusercontent.com, no credential) whenever the Token usage modal opened with a cache older than six hours, with no off switch and no trace: a table served from the baked-in defaults read as live, and a failed fetch was swallowed by a bare return. ROMP_PRICE_FEED=off copies the model catalog's switch (ROMP_MODEL_CATALOG=off: the same stripped, case-folded read, placed as the first statement of _refresh_remote_prices, the one function a fetch can start in, before the TTL check and the stamp) and goes one step past the catalog's silent off: the state is said where the user looks. One function, _price_feed_status, computes the block the /analytics payload carries as priceFeed (outside the 15 s memo on both roads) and /version carries beside modelCatalog, so the modal, /version and a curl cannot disagree.

What the user sees, on one muted line under the modal's footnote, worded by gear.js raPriceNote from the payload's block: with the feed live, `prices: live feed, fetched 4 minutes ago` (the age in plain words from the kernel's ageS); with the switch on, `prices: baked-in defaults; live feed off (ROMP_PRICE_FEED=off)`; after a failed fetch, `prices: baked-in defaults; the last feed fetch failed (HTTPError: HTTP 500)` (a reason class, never the response body or the URL); before any fetch has landed, `prices: baked-in defaults; nothing fetched from the feed yet` (the modal's first open reads this, since the payload is built before the fetch it starts lands, and the next open reads the feed); after a fetch that matched no baked-in id, `prices: baked-in defaults; the feed matched no known model`. A payload without the block (an older kernel) renders no line. Under off a cache already in process memory keeps serving with its age said: the switch stops traffic, not data, and there is no cache file. Stderr, in the catalog's idiom: `price feed: off (ROMP_PRICE_FEED=off); the cost view prices tokens from the baked-in table` once per kernel life at the first refused attempt (a kernel where nobody opens the modal says nothing), and `price feed: fetch failed (<reason class>); the cost view prices tokens from the baked-in table` once per failed fetch, which the six-hour TTL bounds to one line per six hours.

T350 kept: _model_prices(refresh=False), the spend guard's road on the pusher's path, is unchanged and never enters _refresh_remote_prices, so it cannot start a fetch with the switch off, on or unset (tests/test_spend_guard.py test_the_guard_never_starts_the_price_feed_fetch, tests/test_price_feed_off.py GuardRoad). The signature _refresh_remote_prices(now), the price-refresh thread kind and the inner def name work are unchanged, so the _THREAD_KINDS register, the stage-marks census, the perf-bench positional call and the test_token_usage.py harnesses that replace the refresh with `lambda now: None` all hold. The suite floors the switch for every test (tests/conftest.py, the model catalog floor's shape, set at import and re-asserted per test; tests/test_price_feed_floor.py pins both), so no test kernel reaches the feed's host; the feed's own tests pop it in setUp.

What still leaves the machine with the feed off, per docs/reference.md and the design note: claude's own model calls and the judges' calls; the kernel's Models API catalog refresh on the apiKeyHelper credential (ROMP_MODEL_CATALOG=off stops it); the fast-mode organisation probe, the second of the two API calls the reference's Service environment and credentials section names as the kernel's own; the release and drift checks over `git ls-remote` (ROMP_UPDATE_CHECK=off, or the gear's update mode off); web push delivery to the push service of any subscribed phone; and traffic to attached machines. Not this PR: the reference's sentence that the kernel makes two API calls of its own (the paragraph in that section beginning "The kernel makes two API calls of its own") is the same claim class as the guide's outbound-traffic correction in hand elsewhere; the price feed is a third outbound request, with no credential, and whoever lands second covers that paragraph. Also not this PR: the models list, web push.

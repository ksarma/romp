A real postal bus started from tests/test_kernel.py's peer-notify guard test (an in-process kernel whose refused bus call revives the bus on a thread, running the postal service's ensure with the test process's environment) and outlived the run in one CI cell of a fork PR, writing into a shared state root every 30 s and turning another module's snapshot test red. The child's environment was the sum of three import-time writes in other modules: tests/test_kernel_tunnels.py's module-level ROMP_POSTAL_PORT (the run's own, so the bus's fixed-port belt licensed the bind) and ROMP_POSTAL_CLIENT_ONLY (inert while peers are on), and the ROMP_SESSIONS_FILE seam ten postal modules set at module level (one live row, so the bus never autostopped). The fix is fitted to the class rather than the instance: the tunnels module sets all three postal legs per test and patches the kernel's import-time BUS_PORT beside them, restored by cleanups; the guard test stubs the revive road (subprocess.run recorded), waits for it and asserts the ensure argv, so a real child is never attempted and a revive no longer attempted fails the test; conftest pops ROMP_POSTAL_PORT before every test; the seam and the postal host move per test in the ten modules; and the repo-wide pin in tests/test_hermetic_kernel_postal.py holds the set of environment names the test modules write at module level EQUAL to a licensed set, each licence checked per write (a value, a per-test re-assert in conftest, a date and the item a temporary licence waits on), with a census command for the counts by name and shape. Beside it, tests/conftest.py gains a run-end check in the controller: every live process whose environment or cwd holds one of the run's temp roots is named (pid, command line, the names it holds the root through, the test that started it) after a bounded wait for its exit, and the run is red; it found the tunnels mocks' orphaned trailing sleep on its first run. Upstream's tests carry the same module-level writes, the same guard test and the same conftest (their PR #999 took the temp-root hygiene the check reads); tests and docs only.

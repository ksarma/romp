Found by review round 4 of fork PR 815 (extra8-1) and ruled for both receivers; round 6 took the receiver in the diff (ui/webview/view-deltas.ts split() refuses the lane as the kernel's _delta_split does, the frame continues whole and the next patch asks for the whole slot) and left the shim as this queued defect, because its fix is not one line: the seed site (LAST[msg.type] = {rev: 0, msg, maps: buildMaps(msg)}) is an upstream line outside the decoder block and buildMaps has no refusal, so closing it means a wrapper that marks the maps at the seed and refuses at applyDelta, two behaviours redefining two upstream functions, plus the fixture's decoder text regenerated. Reachability is nil by construction: the shim's socket is to the kernel that rendered it, and that kernel never emits a patch for such a payload (_delta_split raises on a lane key carrying the separator, _delta_parts sends the slot whole on every push).

Mechanism: buildMaps keys a dictlist item as lane + SEP + its id field, so a lane named "a" + SEP + "b" holding an item "c" and a lane "a" holding an item "b" + SEP + "c" file under one key; the seed accepts both, and applyDelta's set for either key lands on whichever the map holds, so the two lanes merge and assemble splits the key at its FIRST separator (laneOf), filing the item under lane "a". No needSlot, no row: the shim has no refusal memory. Reproduction, in a vm over the fixture's decoder text (the pipe test's harness): seed LAST.bars over {type:"bars", turns: {["a" + SEP + "b"]: [{id: "c"}]}, judging: {}, messages: []} with maps: buildMaps(msg), then applyDelta({type:"delta", slot:"bars", base: 0, rev: 1, coll: {turns: {set: {["a" + SEP + "b" + SEP + "c"]: {id: "c", n: 2}}}}}) returns a frame whose turns carries lane "a" with the item and no lane "a" + SEP + "b", where the receiver in ui/webview/view-deltas.ts returns null and asks needSlot. The one-line shape round 6 did not take: a line inside the block after applyDelta that rebinds buildMaps to mark maps.__unkeyable when any dictlist lane name carries SEP, and applyDelta to delete LAST[d.slot] and return null when the held maps carry the mark (the upstream null arm above the block then sends needSlot); function hoisting makes both rebinds valid there. Take it with a pin against the fixture's decoder in pipe-view-deltas.test.ts and the fixture regenerated, or close the entry when the shim is retired for the shared receiver.

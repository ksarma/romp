Upstream ships the walk this pins: the wake-only mode is its #936, the parse gate its T401 and the shared decision read its #1141, and jobs stage 1 (fork PR 784) made the wake-only look record and skip on the ten-file key. Fold ruling A condition 7 required exactly one shared load per alive session with the toggle off; stage 1's first wording made that at most one and dropped the floor, and the reviewer's ruling of 2026-09-19 restored it: at most one shared goal-store load per alive session per pass, exactly one on a pass whose look runs, zero on a pass whose look is skipped (a skipped look repeats its verdict and writes nothing, so it needs no data). The ruling asked for a test that counts loads per pass against whether the look ran or skipped, red in both directions, with a counter added if none exists. None did: memos.nudgeWalk counted looks, parses and skips but not the store reads, and memos.shared counts every reader's calls on the shared cache, not the walk's. So this adds memos.nudgeWalk.loads, bumped at the walk's one call site (the read ruling A counted; the placement gate's post-derivation currency re-read is the gate's own, ruling A's open item, and is not counted), names it in the _PerfStats gloss and the reference's memos.nudgeWalk entry, states condition 7 in one sentence in the reference's jobs block, and pins it in tests/test_nudge_walk_one_load_per_pass.py: the real pass over two alive sessions with real transcript files and stores, a recorder on the name the walk resolves at call time (km.jd.load_goals_shared_or_fault) that records the caller and calls through, and the served counter beside it. Per session: exactly one load on the first pass and on a ledger-driven run pass (the gate served, one loader call in total), zero on the skip passes, one beside zero when one session's transcript moves; the gate's re-read once per derived session; no writer load; a look the state gates end before the store read takes none. Tier fix because a served counter is added. Mutations, each landed and reverted: a load in the skip path (a read before the memo is consulted, or the skip's early return dropped) reds the skip pass on the floor-on-a-skip assertion; the load gone from the run path (a stale per-sid snapshot reused) reds the run pass on the floor-on-a-run assertion.

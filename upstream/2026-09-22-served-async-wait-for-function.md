A wait that gated nothing, and a seed race beside it. Playwright 1.62.1 (vscode-extension/package-lock.json) evaluates a waitForFunction predicate once and resolves on a truthy result; an async predicate returns a promise, truthy, so the wait resolved on the first call whatever the promise resolved to (measured: `async () => false` under a 3000 ms bound returned in 20 ms with the value false; the sync `() => false` timed out at 3003 ms). The Task tracking switch lab awaited the kernel /version switch that way after both flips, so its two waits enforced nothing: a hygiene defect of the lab in its own right (in this lab the reads after them held the value anyway, since the kernel writes the switch before it echoes the gear). The driver now polls the same read in a bounded loop and records the elapsed time and a timeout; so the poll is seen to wait, the driver answers its own first five MARKED /version reads after each click with the pre-flip value (a `?driver=1` query the kernel's route ignores, since it dispatches on the parsed path), and an unmarked read, the page's own included, reaches the kernel and gets a live answer, which a read of the shell's shape inside each window and a count of the page's unmarked answers pin. The lab's seed-mark race, the mechanism behind its CI reds, is fixed event-keyed: an ON feed frame with a payload landing between the seed and the off frame rewrites the badge store and prunes the seeds (feed.ts mirrorBadges), which no driver-side wait orders; the pane's own record of received frames now replants the seed on every ON frame's arrival until the first off frame, the seed pin derives its expectation from that record, and every run plants one such frame (needFullFeed through the pane's own send) and waits for its arrival before the click, so the repair carries its own pin. A text pin refuses an async predicate handed to waitForFunction anywhere in the browser-driving directories, by literal (behind leading comments or enclosing parentheses too), by a name bound to an async function, or through a wrapper, and a census holds those directories to every tracked file that holds the call.

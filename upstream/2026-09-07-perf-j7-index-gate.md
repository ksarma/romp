The captioner and archiver ran every discovered session on every pass: the caption file read three times, the unit cache read and decoded, the archive record read, to find that nearly every session owed nothing (418 of the index tier's 677 samples in the 120 s steady profile, about 155 ms of the pass under load). Both per-session bodies are now gated stages: a session is skipped when its pinned parse pair, captions file, archive record and unit cache are identical to the last run that found no work and voided no read, and a session is stamped at pass end only when neither body found work for it (a caption owed or an archive refresh due, counted before the budget and fairness caps) and neither marked the run. The signature carries no goal store: the hit path reads none, and the miss path either publishes the unit cache (moving its identity, one redundant run) or stands down over a fallback view (marking the run), so a store change alone cannot change what the ungated pass would read. The five idle-path readers are strict about files that exist: absent stays a state; a failure marks the run and writes one judge-errors row per failure episode (captions-unreadable, session-archive-unreadable, units-cache-unreadable, units-cache-write-failed), and the bodies stand down for that session rather than caption against a done set or rebuild over a record the pass could not read; an archive record that reads but is not one is content, rebuilt by the archiver with the row still written. tasks_for publishes no cache, and marks the run, when the pair its parse was served under is not the pinned pair (a cut that moved between the pin and the parse: the cache would hold the cut world's tasks under the uncut key). A crash in either body is caught per session and the pass goes on. Bench (private copies of the state copy, judge paused, 31 sessions, placements and captions sealed, 6 passes, two back-to-back pairs): index idle 0.146/0.147 s of CPU per pass before, 0.013/0.005 s after (99-100% skipped); the unsealed work regime and the whole triage pass are unchanged within the box's noise. The gate never withholds a caption or an archive write the ungated pass would have made: every input the bodies read is in the signature, held by the FsCompleteness check over a warm unit cache with the store outside the allowed set.
